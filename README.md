# The Omics Field Guide

A free, comprehensive guide to omics analysis: molecular biology foundations (central dogma, splicing, mutations), every major omics layer (genomics, epigenomics, transcriptomics, single-cell and spatial, proteomics, metabolomics, microbiome), algorithms, ~250 tools with their aims and levels, published benchmarks, multi-omics integration, and open research questions.

**Read it:** https://kianooshnaghibzadeh.github.io/omics-field-guide/

Author: Kianoosh Naghibzadeh
