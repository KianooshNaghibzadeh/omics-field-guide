About this guide

The Omics Field Guide is a free, independent resource for students and researchers starting out in omics and bioinformatics. If you find an error or an outdated benchmark, please send an email with the chapter name and a reference, and it will be corrected in the next edition.

If you use this guide in teaching or a publication, please cite it as: Naghibzadeh K. The Omics Field Guide. 2026. https://kianooshnaghibzadeh.github.io/omics-field-guide/
