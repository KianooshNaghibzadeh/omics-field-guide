The layers

A map of the -omes

"-omics" means measuring all, or nearly all, members of a class of molecules at once, without choosing them in advance. That shift from hypothesis-first to measure-everything changes the statistics: you test thousands of features with few samples, so multiple testing, normalisation and study design dominate.

Three properties that shape every analysis

p ≫ n

Far more features (p) than samples (n). Classical regression breaks down; you need regularisation, dimensionality reduction, empirical Bayes shrinkage and false discovery rate (FDR) control (Benjamini–Hochberg, Storey's q-value).

Measurements are relative

Sequencing returns a fixed number of reads per library, so counts are compositional: one feature rising forces others down. Normalisation (size factors, TMM, CLR) tries to recover comparable scales. Spike-ins can restore absolute scale.

Technical variation is large

Batch, operator, reagent lot, run date and sample handling can explain more variance than biology. Randomise, block and record; correct afterwards only when the design allows it.

The generic analysis arc

Every layer follows a similar arc, even though the tools differ:

  1. Design: question, replicates, power, randomisation, controls, metadata standards.
  2. Primary processing: instrument signal to reads or spectra; QC (FastQC, MultiQC; PTXQC for proteomics).
  3. Secondary processing: reads to features (alignment, quantification, variant/peak calling, identification).
  4. Feature-level QC and normalisation: filter low-quality samples and features, correct library size or loading, examine batch with PCA.
  5. Statistical modelling: differential abundance, association, clustering, prediction.
  6. Interpretation: annotation, enrichment, networks, integration with other layers and with prior knowledge.
  7. Validation and sharing: independent cohort, orthogonal assay, data deposition (GEO, PRIDE, MetaboLights, EGA).
From sample to file

How omics data are generated

Every file you analyse is the end of a physical process: a sample was collected, molecules were extracted, converted into something an instrument can read, and measured. Knowing that process tells you where the artefacts in your data come from and which parameters in your pipeline exist to correct them.

The common path

  1. Study designQuestion, groups, replicates, randomisation, metadata sheet
  2. Sample collectionBlood, tissue, cells, stool, swab; time to freezing; preservative (EDTA, PAXgene, RNAlater, FFPE)
  3. ExtractionIsolate DNA, RNA, protein or metabolites; measure quantity and integrity (Qubit, RIN/DV200, BCA)
  4. ConversionLibrary preparation for sequencing, digestion for proteomics, derivatisation for GC-MS
  5. MeasurementSequencer, mass spectrometer, array scanner, NMR, microscope
  6. Raw dataFASTQ / POD5 / BAM, RAW / mzML, IDAT, FID, images
  7. QC & depositRun metrics, sample QC, upload to GEO/SRA/PRIDE/MetaboLights
Pre-analytical variation

Many apparent biological signals come from handling. RNA degrades within minutes at room temperature; hypoxia during surgery changes gene expression; metabolites keep changing in unfrozen blood; formalin fixation damages DNA (C>T artefacts) and fragments RNA. Record collection time, processing delay, freeze–thaw cycles and storage duration for every sample, and keep them balanced across groups.

Sequencing libraries

A sequencing library is a collection of DNA fragments, each flanked by known adapter sequences that let the sequencer capture, amplify and read them. Whatever the starting molecule (genomic DNA, cDNA from RNA, bisulfite-converted DNA, immunoprecipitated chromatin, Tn5-tagged fragments), the result has the same structure:

  • Fragmentation: sonication, enzymatic shearing or transposase (tagmentation) produces fragments of ~200–600 bp for short reads. Long-read libraries keep fragments of 10–100 kb or longer.
  • End repair, A-tailing and adapter ligation attach adapters; tagmentation (Nextera) fragments and adds adapters in one step.
  • PCR amplification adds index sequences and enriches adapter-ligated fragments. PCR creates duplicates and GC bias; PCR-free WGS avoids this when input DNA allows.
  • Unique molecular identifiers (UMIs): random barcodes attached before amplification, so reads from the same original molecule can be collapsed. Essential for single-cell counting and ultra-low-frequency variant detection.
  • Target enrichment (exomes, panels): hybridisation capture with biotinylated probes or amplicon PCR. Coverage then depends on probe efficiency, which is why exome depth is uneven.
  • Library QC: fragment size (Bioanalyzer/TapeStation), concentration (qPCR) and adapter-dimer contamination.

Short-read sequencing by synthesis (Illumina)

Library fragments bind to a flow cell and are copied in place into clusters of ~1,000 identical molecules (bridge amplification or exclusion amplification on patterned flow cells). Then sequencing proceeds in cycles. In each cycle a polymerase adds one fluorescently labelled, reversibly terminated nucleotide to every cluster; a camera images the flow cell; the dye and terminator are cleaved; the next cycle begins. The colour of each cluster in each cycle is the base.

Errors grow along the read because clusters lose synchrony (phasing): some molecules fall a base behind or jump ahead, blurring the signal. That is why base quality drops toward the 3′ end of reads. Long-read sequencing

PacBio HiFi (SMRT)

A single polymerase copies a circularised DNA molecule (SMRTbell) inside a tiny well (zero-mode waveguide) while fluorescent nucleotides are detected in real time. Because the molecule is circular, the polymerase reads it many times; a consensus of these passes gives 15–25 kb reads at ~99.9% accuracy. Polymerase kinetics (pauses) reveal methylation.

Oxford Nanopore

A motor protein ratchets a single DNA or RNA strand through a protein pore in a membrane. Ionic current through the pore depends on the ~5–9 bases inside it at each moment. A neural-network basecaller translates the current trace (the "squiggle") into bases, and modified bases (5mC, 6mA, m6A) change the current, so they are detected directly. Read length is limited only by the molecule.

Arrays

Microarrays measure many known targets at once by hybridising labelled sample to millions of immobilised probes. SNP genotyping arrays (e.g. Illumina Global Screening Array, UK Biobank Axiom) read the two alleles of ~0.6–2 million variants from two colour channels; the ratio gives the genotype (plotted as genotype clusters) and the B-allele frequency also reveals copy number. Methylation arrays (EPIC) read bisulfite-converted DNA at ~935k CpGs. Expression arrays are now largely replaced by RNA-seq, but decades of array data remain in GEO.

Mass spectrometry

Proteomics, metabolomics and lipidomics are mostly measured by mass spectrometry (MS). Molecules are separated by liquid or gas chromatography, ionised (electrospray for LC, electron ionisation for GC, MALDI for imaging), then the mass analyser separates ions by mass-to-charge ratio (m/z):

In tandem MS (MS/MS), a selected ion is fragmented by collision with gas and the fragments are measured. Fragment patterns identify peptide sequences and small-molecule structures. Raw files are vendor-specific (.raw, .d, .wiff) and are converted to open mzML for most open-source tools.

NMR, imaging and other readouts

  • NMR spectroscopy measures how atomic nuclei (¹H, ¹³C) in a magnetic field absorb radio-frequency energy; chemical shifts identify functional groups. Quantitative and reproducible, used in large cohort metabolomics.
  • Imaging-based spatial omics (MERFISH, Xenium, CosMx) hybridise fluorescent probes in repeated rounds; each transcript's colour sequence across rounds forms a barcode decoded to a gene. Protein imaging (CODEX, IMC) uses barcoded or metal-tagged antibodies.
  • Flow and mass cytometry (CyTOF) measure ~20–50 proteins per cell in millions of cells.
  • Affinity proteomics (Olink, SomaScan) converts protein binding into DNA barcodes or aptamer signals read by sequencing or arrays.

DNA layer

Genomics

Reading DNA and finding where it differs. Germline genomics asks which inherited variants explain disease or traits; somatic genomics asks which acquired variants drive cancer and clonal expansion; assembly asks what the genome actually looks like when no reference fits.

Research questions

  • Which variant explains this patient's rare disease? (diagnostic yield of WES is ~25–40%, WGS adds several percent more)
  • Which loci are associated with a complex trait, and which variant and gene in each locus is causal?
  • How much heritability do rare and structural variants explain beyond common SNPs?
  • Which somatic mutations drive a tumour, in what order, and which therapies do they predict?
  • What is the full structural diversity of human genomes across ancestries (pangenome)?
  • Can polygenic scores predict risk equally well across populations?

How genomic data are generated

  1. SampleBlood (EDTA), saliva, buccal swab, fresh-frozen or FFPE tissue; tumour plus matched normal for somatic work
  2. DNA extractionSilica columns or magnetic beads; high-molecular-weight kits (>50 kb) for long reads
  3. DNA QCConcentration (Qubit), purity (A260/280 ≈ 1.8), integrity (DIN, pulsed-field gel)
  4. LibraryPCR-free WGS; exome capture with probes (~35–60 Mb); amplicon panels; size selection for HiFi/ONT
  5. Sequencing2 × 150 bp to ~30× (germline) or 60–100× tumour; HiFi 15–25 kb; ONT ultra-long
  6. Raw outputFASTQ (short reads), unaligned BAM (PacBio), POD5 signal (ONT)

Arrays follow a different route: DNA is amplified, fragmented, hybridised to probes on a BeadChip and scanned into IDAT intensity files, then genotypes are called from the two allele intensities (GenomeStudio, gtc2vcf) and missing variants are imputed.

Reading aligned sequences

After alignment, every read sits at its position on the reference. A genome browser such as IGV shows this as a pileup: bases that match the reference are drawn as plain bars, and only differences are shown. Real variants appear in a consistent fraction of reads from both strands; sequencing errors appear in single reads at low quality.

A caller summarises this evidence as one line of a VCF file:

The germline short-read pipeline

  1. QC and trimming (FastQC, fastp): adapters, quality, duplication.
  2. Alignment to GRCh38 (BWA-MEM2; minimap2 for long reads). Uses the Burrows–Wheeler transform/FM-index to find exact seed matches quickly, then Smith–Waterman local alignment. Output: SAM/BAM/CRAM with mapping quality (MAPQ = −10 log10 P(mapped position wrong)).
  3. Duplicate marking (Picard, samblaster, GATK MarkDuplicatesSpark): PCR and optical duplicates inflate confidence.
  4. Base quality score recalibration (BQSR): models systematic quality errors by machine cycle and context. Less important with modern instruments and with DeepVariant.
  5. Variant calling: GATK HaplotypeCaller re-assembles local haplotypes with a de Bruijn graph and computes genotype likelihoods with a pair-HMM; DeepVariant encodes read pileups as images and classifies genotypes with a CNN; Strelka2, FreeBayes, Octopus and DRAGEN are alternatives. Cohort calling uses gVCFs and joint genotyping (GATK GenotypeGVCFs, GLnexus).
  6. Filtering: VQSR (Gaussian mixture on annotations) for large cohorts, hard filters for small ones, or learned filters.
  7. Annotation: VEP, ANNOVAR, SnpEff add gene, transcript and consequence, population frequency (gnomAD), predictions (CADD, REVEL, SpliceAI, AlphaMissense) and clinical databases (ClinVar).
  8. Prioritisation: Exomiser and LIRICAL combine variant scores with patient phenotypes (HPO terms); inheritance-mode filters for trios.
Key idea

Variant calling is a statistical inference, not a lookup. A genotype call is the most likely genotype given read evidence, base and mapping qualities and a prior. Report and filter on genotype quality (GQ), depth (DP) and allele balance, and use benchmark regions to know where calls can be trusted.

Structural variants and copy number

Short-read SV callers combine three signals: discordant read pairs (unexpected insert size or orientation), split reads (one read spanning a breakpoint), and read depth. Assembly-based callers reconstruct breakpoint sequence. Manta, DELLY, LUMPY/smoove and GRIDSS2 are widely used, often merged with SURVIVOR or Jasmine. Long-read callers (Sniffles2, cuteSV, pbsv, SVIM) and assembly-based comparison (PAV, SVIM-asm, dipcall) recover far more SVs, especially insertions in repeats. For copy number: CNVkit and GATK gCNV (exomes and panels), CNVnator and Canvas (WGS), ASCAT, FACETS and PURPLE (tumour allele-specific copy number with purity and ploidy), and GISTIC2 (recurrent CNAs across tumours).

Somatic variant calling

Tumour samples are mixtures of tumour and normal cells, often with subclones, so somatic variants may appear at 5% VAF or lower. Use a matched normal, a panel of normals, and germline resource filtering (Mutect2 with FilterMutectCalls, Strelka2, VarDict, LoFreq). FFPE samples cause C>T deamination artefacts, and oxidation causes G>T artefacts; orientation-bias filters address both. Ultra-sensitive applications (minimal residual disease, liquid biopsy) need unique molecular identifiers (UMIs) and duplex sequencing to suppress errors below 10−6.

De novo assembly and pangenomes

When the reference is incomplete or absent, reads are assembled. Overlap-layout-consensus and string graphs (hifiasm, HiCanu, Flye, Shasta) handle long reads; de Bruijn graphs (SPAdes, MEGAHIT) handle short reads. Hybrid approaches (Verkko) combine HiFi with ultra-long ONT for telomere-to-telomere assemblies; Hi-C or parental data (trio binning) phase haplotypes. Assess with N50, BUSCO completeness, Merqury k-mer QV and Inspector. The Human Pangenome Reference Consortium builds graph references (minigraph-Cactus, PGGB) that reduce reference bias; vg giraffe aligns reads to graphs.

Population and statistical genetics

  • GWAS: test each variant for association with a trait while controlling population structure. PLINK 2 for QC and simple models; mixed models handle relatedness and structure at biobank scale (REGENIE, SAIGE, BOLT-LMM, fastGWA). Genome-wide significance is conventionally p < 5×10−8.
  • Imputation: infer untyped variants from haplotype reference panels (TOPMed, 1000 Genomes, HRC) with Beagle 5, Minimac4 or IMPUTE5; pre-phasing with SHAPEIT5 or Eagle2.
  • Heritability and genetic correlation: LD score regression (LDSC), GCTA-GREML, S-LDSC for enrichment in annotations (cell-type-specific enhancers).
  • Fine-mapping: SuSiE, FINEMAP, PolyFun (functional priors) output credible sets of likely causal variants.
  • Polygenic scores: PRS-CS, LDpred2, SBayesRC, PRS-CSx (multi-ancestry). Evaluate with incremental R² or AUC in held-out cohorts of each ancestry.
  • Rare-variant burden tests: SKAT-O, ACAT, gene-based burden in exome biobanks.

Benchmarks

Pitfall

Benchmarks such as Genome in a Bottle cover "high-confidence" regions, which historically excluded the hardest parts of the genome. A pipeline scoring 99.9% F1 there may do much worse in segmental duplications, the MHC or medically relevant genes with paralogs (e.g. SMN1/2, PMS2, CYP2D6). Check stratified performance (GIAB stratification BEDs with hap.py or vcfdist), not only the headline number.

Research gap
  • Variant calling against pangenome graphs, and benchmarks that represent diverse ancestries.
  • Joint calling of SNVs, SVs, repeat expansions and methylation from one long-read run.
  • Interpretation of non-coding and structural variants in rare disease, where most unsolved cases may sit.
  • Polygenic score portability, calibration and clinical utility across ancestries.
  • Somatic mosaicism and clonal haematopoiesis detection in normal tissues.
DNA layer · regulation

Epigenomics

Heritable or stable changes in gene activity that do not change DNA sequence: methylation of DNA, chemical marks on histones, which DNA is accessible, where transcription factors sit, and how chromosomes fold in 3D. Epigenomics explains how one genome makes hundreds of cell types.

Research questions

  • Which regulatory elements are active in this cell type, and which genes do they control?
  • How do disease-associated variants change TF binding, accessibility or methylation?
  • Does methylation mark disease state, ageing (epigenetic clocks), exposure (smoking) or cell composition?
  • Can methylation patterns in cell-free DNA detect cancer and identify its tissue of origin?
  • How does 3D genome folding (loops, TADs) control enhancer–promoter communication?

DNA methylation

In mammals methylation is mostly 5-methylcytosine (5mC) at CpG dinucleotides. About 70–80% of CpGs are methylated, except in CpG islands at active promoters. DNMT3A/B establish new methylation, DNMT1 maintains it through replication, and TET enzymes oxidise 5mC to 5hmC, 5fC and 5caC on the way to demethylation. Promoter methylation is associated with silencing; gene-body methylation correlates with active transcription.

Analysis: bisulfite-aware alignment (Bismark, bwa-meth, BSBolt) uses three-letter alignment (C/T and G/A converted genomes). Methylation is then extracted per CpG (MethylDackel, Bismark extractor). Arrays are processed with minfi, SeSAMe or ChAMP (normalisation: Noob, BMIQ, functional normalisation). Differential methylation is tested per CpG (methylKit, DSS, limma on M-values) or per region (DMRcate, bsseq/BSmooth, dmrseq, metilene). Because blood and tissue methylation is dominated by cell composition, estimate proportions (Houseman method, EpiDISH, MethylCIBERSORT) and adjust.

Epigenetic clocks

Penalised regression on methylation predicts age with striking accuracy: Horvath's multi-tissue clock (353 CpGs, 2013) and Hannum's blood clock. Later clocks predict health outcomes rather than chronological age: PhenoAge, GrimAge and the pace-of-ageing measure DunedinPACE. Their biological meaning, and whether interventions that change them change health, are open questions.

Chromatin accessibility

ATAC-seq uses hyperactive Tn5 transposase to insert sequencing adapters into open chromatin. It needs ~50,000 cells (or single nuclei in scATAC). Fragment lengths show nucleosome-free (<100 bp), mono-nucleosome (~200 bp) and di-nucleosome peaks; the TSS enrichment score and fragment-size periodicity are the main QC metrics. DNase-seq and MNase-seq are older alternatives.

Pipeline: trim (Nextera adapters), align (Bowtie2 or BWA), remove mitochondrial reads and duplicates, shift reads +4/−5 bp for Tn5 offset, call peaks (MACS2/3, Genrich, HMMRATAC), build a consensus peak set, count (featureCounts), test differential accessibility (DESeq2/edgeR, DiffBind, csaw). Downstream: motif enrichment (HOMER, MEME-ChIP), TF footprinting (TOBIAS, HINT-ATAC), and per-sample TF activity (chromVAR).

3D genome

Hi-C crosslinks chromatin, digests it, ligates nearby fragments and sequences the junctions, giving a genome-wide contact matrix. Micro-C uses MNase for nucleosome resolution; capture Hi-C, HiChIP and PLAC-seq focus on promoters or protein-anchored contacts. Processing (Juicer, HiC-Pro, distiller, HiCExplorer) produces .hic or .cool/.mcool files, normalised by iterative correction (ICE) or Knight–Ruiz balancing. Features are then called: A/B compartments (eigenvector of the correlation matrix), TADs (insulation score, Arrowhead, TopDom), loops (HiCCUPS, Mustache, chromosight), and differential contacts (diffHic, multiHiCcompare, CHESS). Contact frequency drops with genomic distance, so all comparisons must account for that distance decay.

Linking regulatory elements to genes

The nearest-gene assumption is wrong for a large share of enhancers. Better approaches use activity and contact together: the Activity-by-Contact (ABC) model (enhancer activity × Hi-C contact), correlations between accessibility and expression across samples or single cells (peak-to-gene links in ArchR, Signac), and CRISPRi screens as ground truth (e.g. ENCODE-rE2G models trained on CRISPR perturbation data).

Pitfall

In EWAS, smoking, age, sex, genotype (meQTLs) and cell composition can all produce differential methylation. A "disease signature" may be a composition signature. Adjust for estimated cell proportions and check whether hits are known meQTLs. Also check causality direction: disease, medication and lifestyle can change methylation rather than the reverse.

  • Causal link from a specific mark to a specific expression change (most epigenomic data are correlational; epigenome editing with dCas9 fusions is starting to test this).
  • Single-cell multi-modal epigenomics (methylation + accessibility + RNA in the same cell) at scale.
  • Haplotype-resolved methylation from long reads and its role in imprinting and allele-specific expression.
  • Enhancer–gene linking in rare cell types and disease states without CRISPR ground truth.
  • Biological interpretation of epigenetic clocks and their response to interventions.
RNA layer

Transcriptomics

Measuring which genes are expressed, how much, and in which isoform. Bulk RNA-seq is the most widely used omics assay in biology, and its statistical tooling is the most mature, so it is the best place to learn the logic that every other layer reuses.

Research questions

  • Which genes change between conditions (disease vs control, treated vs untreated, time points)?
  • Which pathways and programmes are active, and which upstream regulators explain them?
  • Which isoforms, fusions, editing sites or allele-specific expression patterns are present?
  • Can expression classify patients (subtypes, prognosis, treatment response)?
  • How do genetic variants affect expression (eQTLs) and splicing (sQTLs)?

Experimental choices that decide what you can analyse

RNA selection

Poly(A)+ captures mature mRNA; rRNA depletion keeps non-polyadenylated and pre-mRNA (intronic reads). Small-RNA libraries for miRNA. Degraded samples (FFPE) need depletion or capture.

Strandedness and length

Stranded libraries (dUTP) resolve antisense transcription. Paired-end 2×100–150 bp helps isoforms and fusions. 3′-tag methods (QuantSeq, BRB-seq) are cheap for gene counts but blind to isoforms.

Depth and replicates

~20–30M reads per sample is typical for gene-level DE; isoform work needs more. Biological replicates matter more than depth: aim for six or more per group when you can.

How transcriptomic data are generated

  1. Sample & stabiliseSnap-freeze, RNAlater or PAXgene (blood) within minutes; RNA degrades fast
  2. RNA extractionTRIzol or column kits; DNase treatment removes genomic DNA
  3. RNA QCRIN (1–10) or DV200 for FFPE; quantity by Qubit
  4. Select RNAPoly(A) capture with oligo-dT beads, or rRNA depletion (keeps non-polyadenylated RNA)
  5. Make cDNAFragment RNA → reverse transcription → second strand with dUTP (marks strand) → adapters → PCR
  6. Sequence~20–40 M read pairs, 2 × 100–150 bp; long-read cDNA or direct RNA for full isoforms

The end product of quantification is a count matrix: genes in rows, samples in columns, each entry the number of reads (or estimated fragments) assigned to that gene. Everything downstream works on this table.

The standard pipeline

  1. QC: FastQC/MultiQC, rRNA content, strand check (RSeQC infer_experiment, salmon's automatic library type), gene body coverage (3′ bias indicates degradation), RIN or DV200 from the lab.
  2. Quantification, two routes:
    • Alignment-based: STAR or HISAT2 to the genome, then featureCounts or HTSeq for gene counts; RSEM for isoforms. Gives BAMs for visual inspection, novel junctions and variant calling.
    • Pseudoalignment / selective alignment: salmon or kallisto match reads to transcript sequences and resolve multi-mapping reads with an EM algorithm. Fast and accurate for annotated transcripts; use salmon with a decoy-aware index. Import with tximport/tximeta to gene level.
  3. Filtering and normalisation: remove genes with very low counts (edgeR filterByExpr). Between-sample normalisation with DESeq2's median-of-ratios or edgeR's TMM. TPM and FPKM are within-sample units for display; do not feed them into count-based DE models.
  4. Exploration: variance-stabilising transform (vst/rlog), PCA, sample-distance heatmaps. Look for outliers, batch effects, sex mismatches (XIST, chrY genes) and sample swaps.
  5. Differential expression: negative binomial GLMs (DESeq2, edgeR) or linear models on log-CPM with precision weights (limma-voom). Include batch and covariates in the design matrix. Use empirical Bayes shrinkage of dispersions and of fold changes (apeglm, ashr) for ranking.
  6. Multiple testing: Benjamini–Hochberg FDR. IHW (independent hypothesis weighting) can increase power.
  7. Interpretation: over-representation (clusterProfiler, g:Profiler, Enrichr), rank-based GSEA (fgsea, GSEA), sample-level scores (GSVA, ssGSEA, singscore), TF and pathway activity from footprints (DoRothEA/CollecTRI with decoupleR, PROGENy), co-expression modules (WGCNA, hdWGCNA for single-cell).
Why the negative binomial

Counts from technical replicates are roughly Poisson (variance = mean). Biological replicates vary more, so variance = μ + αμ², where α is the dispersion. With three replicates you cannot estimate α per gene reliably, so DESeq2 and edgeR borrow information across genes: they shrink each gene's dispersion toward a trend fitted against mean expression. That shrinkage is the main reason these tools work with small sample sizes.

Beyond gene counts

  • Isoforms: short-read isoform quantification is uncertain when isoforms share most exons. Long-read RNA-seq (PacBio Kinnex/Iso-Seq, ONT cDNA or direct RNA) sequences full transcripts. Tools: IsoQuant, Bambu, FLAIR, StringTie2, TALON, ESPRESSO; SQANTI3 classifies and filters isoforms against the annotation.
  • Splicing: see the splicing chapter (rMATS, LeafCutter, MAJIQ, SUPPA2).
  • Fusion genes: STAR-Fusion, Arriba, FusionCatcher; important in leukaemia (BCR::ABL1), sarcomas and prostate cancer (TMPRSS2::ERG).
  • Allele-specific expression: phASER, GATK ASEReadCounter; WASP-style filtering corrects reference mapping bias.
  • RNA editing: REDItools, SPRINT, JACUSA2.
  • Small RNA: miRDeep2, sRNAbench, nf-core/smrnaseq; miRNA target prediction with TargetScan and miRDB.
  • Deconvolution: estimate cell-type proportions from bulk with CIBERSORTx, MuSiC, BayesPrism, EPIC, quanTIseq, using single-cell references.
  • Nascent and decay: PRO-seq, TT-seq and metabolic labelling (SLAM-seq) separate transcription from degradation.

Pitfalls
  • Confounded design: if all cases were sequenced in batch 1 and all controls in batch 2, no software can separate batch from biology.
  • Pseudoreplication: multiple wells from one donor are not independent biological replicates.
  • Calling a pathway "activated" from an over-representation test that ignores direction and gene–gene correlation.
  • Using a genome-wide background for enrichment when only expressed genes could have been detected.
  • Treating "not significant" as "not changed"; with low power, absence of evidence is not evidence of absence.
Research gap
  • Accurate isoform-level quantification and differential testing, especially from long reads at modest depth.
  • Calibrated DE in large heterogeneous cohorts, where standard parametric tools can inflate false positives.
  • Separating transcriptional from post-transcriptional regulation in standard steady-state data.
  • Robust deconvolution when reference single-cell data come from a different platform or disease state.
